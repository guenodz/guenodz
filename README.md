## 🧱 How I build

- **Kotlin** and **Jetpack Compose** for everything UI
- **Multi-module Clean Architecture** with MVVM or MVI, so a new surface like TV or Auto is a new module, not a rewrite
- **Media3 / ExoPlayer** for audio and video playback
- **Room, Retrofit, Hilt, WorkManager, Firebase** for the rest of the stack
